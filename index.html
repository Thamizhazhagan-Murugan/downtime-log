How the clock works
One state at a time
The line is always in one state. Each entry stops the running timer and starts the next one, so every minute of the shift is either extrusion or downtime.
Main machine (press)
Its running state is extrusion time. Every other state is downtime until someone logs the running state again.
Stops the line right away
Puller and stretcher. An issue stops the extrusion clock until the machine is back to Auto. Then the line returns to whatever the press is doing.
Line keeps running
Feeding line. Issues do not stop extrusion unless someone presses Stop the press. From then on the downtime goes to that machine until it is back to Auto.
Group
ZPE A and ZPE B. One down does not stop the line. When all machines in the group are down together for the delay, the press stops and the downtime goes to the group.
Availability
Extrusion time ÷ (extrusion time + downtime). Time before the first entry is shown as not logged and left out.
Sign-in and roles
People sign in with Google or email. New accounts wait for an admin to approve them. Only the main admin can make or remove admins. The database rules enforce the same, so the app cannot be used to get around them.
